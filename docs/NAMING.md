# Naming

Checked for collisions against existing AI-assistant products and GitHub projects.

## Picked: Sable

A sable is a small, fast marten. Short, five letters, easy to say, easy to draw
as a mascot, and it fits the animal-mascot convention the space already has.
Scattered projects share the name (a security-research agent, a landing-page
generator, an `sable-ai` org) but none owns "Sable = personal assistant".

Do before committing: npm scope check, trademark search, domain check
(sable.sh, getsable.com).

## Runners-up

**Pocketwatch.** Best metaphor of the lot: something personal you carry that is
always ticking, which maps directly onto the heartbeat. Only light collisions.
Loses on length.

**Marlo.** Clean and human. There is an active `marlo-ai` org and a personal
iMessage concierge bot with the same name, so the concept overlap is real.

## Rejected

| Name | Why |
|---|---|
| Tumbler | Technically the freest name, but "tumbler" reads as crypto mixer |
| Mica, Otto, Nimbus, Lumen | Multiple existing personal-assistant projects |
| Quill | Owned by AI writing tools |
| Kite | Defunct code-completion tool still holds the association |
| Vesper | Scattered Windows and Discord assistant projects |
